Image colorization is the task of predicting plausible color values for each pixel in a grayscale image. In this project, images are represented in the CIELAB color space, where the L channel encodes luminance and the a and b channels encode chrominance. A U-Net–based model is trained to take the L channel as input and predict the corresponding (a, b) channels. The project investigates two approaches: a regression-based method that directly predicts continuous color values, and a classification-based method that predicts a distribution over discretized color bins. While regression tends to produce smoother but desaturated results and classification yields more vivid but sometimes inaccurate colors, this project also proposes a hybrid approach that combines both methods to improve color fidelity and realism.
